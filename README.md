## 🤖 Sobre este repositório

Este repositório nasceu de uma ideia simples: usar a IA como **parceira de ensino** para criar materiais de programação claros, visuais e diretos ao ponto — sem enrolação, sem linguagem complicada.

Cada curso foi desenvolvido em conjunto com **Claude (Anthropic)**, com foco em:

- ✅ Explicações em português, acessíveis para iniciantes
- ✅ Exemplos de código real que você pode rodar agora
- ✅ Progressão lógica do básico ao avançado
- ✅ Exercícios e desafios práticos
- ✅ Formatação pensada para leitura no GitHub

> 💡 **Experimento de aprendizado:** Este projeto também demonstra como a IA pode ser usada como ferramenta de estudo — tanto para criar conteúdo quanto para tirar dúvidas e praticar conceitos.

## 🧠 O que você vai aprender

### 📘 Markdown Completo
> Ideal para quem quer escrever documentação, READMEs e anotações com qualidade profissional.

Cabeçalhos, listas, tabelas, links, imagens, blocos de código com realce de sintaxe, recursos do GitHub como badges e diagramas Mermaid, e como escrever um README profissional do zero.

---

### 🧠 Lógica de Programação (Python)
> Para quem está começando a programar e quer construir uma base sólida antes de mergulhar em frameworks e bibliotecas.

Algoritmos e fluxogramas, variáveis e tipos de dados, estruturas de decisão (`if/elif/else`), loops (`for/while`), listas, dicionários, funções, recursão, busca e ordenação, depuração e tratamento de erros.

---

### ⛏️ Skript — Minecraft
> Para quem quer criar plugins personalizados no servidor Minecraft sem precisar saber Java.

Eventos, condições e efeitos, variáveis (locais, globais e listas), comandos customizados com permissões e cooldown, loops, funções reutilizáveis, 4 projetos completos prontos para usar (homes, PvP, economia, sistema de rank), e os addons mais populares da comunidade.

---

### 🗄️ SQL para TI
> Focado no dia a dia de quem trabalha com dados, suporte, infraestrutura ou desenvolvimento.

SELECT, WHERE, JOINs, agregações, GROUP BY, subqueries, Window Functions, CTEs, manipulação de dados (INSERT/UPDATE/DELETE), índices e performance, e 6 casos reais de TI: dashboard de tickets, alertas de infra, auditoria de acessos, análise de SLA, correlação de deploys com incidentes, e queries de manutenção de banco.

---

### 🐙 Git e GitHub
> O controle de versão é a habilidade mais valorizada no mercado — independente da linguagem ou área.

Conceitos fundamentais (Working Directory, Staging, Commits), branches, merge e rebase, desfazendo erros com `restore`, `reset`, `revert` e `stash`, repositórios remotos, fork, pull requests, code review, GitHub Actions para CI/CD, Git Flow vs GitHub Flow, e soluções para as 8 situações mais comuns do dia a dia.

## 🚀 Como usar este repositório

**1. Estude pelo GitHub mesmo**
Basta clicar nos arquivos `.md` acima — o GitHub renderiza tudo automaticamente, com formatação, tabelas e código colorido.

**2. Clone e leia offline**
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

**3. Execute os exemplos**
Cada curso indica as ferramentas necessárias. Para começar sem instalar nada:

| Curso | Ferramenta online |
|---|---|
| Python / Lógica | [python.org/shell](https://www.python.org/shell/) |
| SQL | [sqliteonline.com](https://sqliteonline.com) |
| Git | [learngitbranching.js.org](https://learngitbranching.js.org/?locale=pt_BR) |
| Skript | Servidor Paper local |

## 🤝 Como a IA foi usada neste projeto

Este repositório é transparente sobre o uso de IA:

| Etapa | IA fez | Humano fez |
|---|---|---|
| **Estrutura do curso** | Sugeriu organização por módulos | Definiu os temas e a progressão |
| **Explicações** | Redigiu o conteúdo técnico | Revisou, ajustou tom e linguagem |
| **Exemplos de código** | Gerou e testou os exemplos | Selecionou os mais didáticos |
| **Exercícios** | Criou desafios por nível | Validou a dificuldade e relevância |
| **Formatação Markdown** | Aplicou toda a formatação visual | Definiu o estilo e padrão visual |

> A IA é uma **ferramenta poderosa de produtividade** — mas o direcionamento, as escolhas pedagógicas e a curadoria do conteúdo são humanas.
